Interactions
• Drag a node to reposition · drag empty canvas to pan
• Wheel / pinch to zoom · + − zoom · arrow keys pan (Shift = faster)
• Hover highlights the neighborhood · click opens the note
• Right-click for actions · cog opens settings (Filters · Groups · Display · Forces)

Demo data: ~25 notes across folders/tags, 4 unresolved (dimmed ghost) links, 1 orphan note. Timestamps span Jan–Nov 2026 so the time-lapse animation (Display tab) is visible.
